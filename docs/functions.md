Ago infers a value's type from a variable's **ending** (`-a` int, `-ae` float, `-es` string, `-uum` any-list, `-u` map, ...). The same endings drive the cast methods below.

## Cast methods (`.x()`)

Any value can be converted to another type by calling the method named for the target ending, e.g. `xa.es()` → string, `luum.a()` → length. Implemented by `AgoType::as_type` in `src/rust/src/casting.rs`.
